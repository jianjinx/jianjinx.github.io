关于

这里是属于我的一方天地。

没有特别的故事要讲，只是想有一个地方可以安安静静地放些东西——也许是一段文字，也许是一张照片，也许只是某个下午发呆时想到的一句话。

这个网站左侧是磨砂玻璃边栏，支持发布和阅读文章。文章用 Markdown 写成，通过 GitHub 同步，所有人可见。也支持 LaTeX 公式和对弈五子棋。

不赶时间，也不急着被谁看见。
